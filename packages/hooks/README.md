# @zed-ui/hooks

React hooks used internally by `@zed-ui/react` (`useDisclosure`, `useControllableState`, etc.).

Installed automatically with `@zed-ui/react`. Import components from `@zed-ui/react` in application code.

```bash
npm install @zed-ui/react @zed-ui/themes react react-dom
```
