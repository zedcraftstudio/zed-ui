# @zed-ui/system

Style props, polymorphic component types, and layout primitives used by `@zed-ui/react`.

This package is installed automatically as a dependency of `@zed-ui/react`. Most applications should import from `@zed-ui/react` instead.

```bash
npm install @zed-ui/react @zed-ui/themes react react-dom
```
